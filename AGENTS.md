# Repository agent instructions

Read [README.md](README.md) for the project scope before changing this repository.

Before pushing changes, follow [Executive-Code-Reviewer.md](Executive-Code-Reviewer.md). Review the complete proposed change and relevant surrounding code, run applicable verification, and report the candidate commit and final verdict. Push only after a **PASS — READY TO PUSH** verdict and within the user's authorization. A changed candidate requires a renewed review.

Apply checks proportionately to the implemented scope. Documentation-only changes do not require application tests when no application exists. Do not report unperformed checks as passed or treat this instruction file as automated Git enforcement.
